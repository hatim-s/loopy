Install

Do the work once.Extract the graph.Run it with control.

Loopy turns one coding agent session into a graph you can read, edit and run again on your own machine. The agent still does the work. The graph decides what happens next.

$ bun add -g loopy
See how it works

Capture loopy import

Do the task once in Codex, Claude Code, OpenCode or Pi. Loopy records the session, or imports one you already ran, as a trace.

Extract loopy extract

A deterministic extractor proposes a graph. No model calls. Every node points back to the trace events behind it. You review, edit and approve.

Run loopy run

The graph runs on your machine through the same CLIs. Loopy owns the order, the checks and the approvals. State lives in local SQLite.

You hold the controls. Try them.

This is the CVE loopy. Start a run, pause it, fork it from a checkpoint. The checks fail once on purpose so you can watch a retry. The run stops at the approval node until you press approve.

    Loopy runs through Codex, Claude Code, OpenCode and Pi. It calls the CLI you already installed, with your login and your settings.

    Each agent node picks its provider, so one loopy can use Codex to write the patch and Claude Code to review it.

    A loopy that rebases your PRs before you wake up.

    Keep open pull requests rebased. Every day at 09:00 it lists open PRs, asks the agent to rebase each onto main, runs a focused check and pushes with --force-with-lease. Conflicts get skipped, never forced.

    Set it up with loopy schedule create --cron '0 9 * * *'. It runs on your machine, so the pushes use your Git credentials.
