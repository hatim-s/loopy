One session in. A runnable graph out.

Loopy is a local graph harness for Codex and Claude Code. It turns a recorded agent session into an execution graph, then runs it on your machine with pause, retry, fork and approvals.

Record

Do the task once in Codex or Claude Code. Loopy imports the recorded session trace.

loopy import
2

Extract

A deterministic extractor proposes a graph with no model calls. Every node links back to the trace events behind it.

loopy extract
3

Run

Approve the graph and run it locally. Loopy owns the order, the checks and the approvals. The agent does the work inside nodes.

loopy run

Runtime controls

Runs are durable. Every attempt and checkpoint is written to SQLite as it happens.

PauseStop between nodes and resume later.
RetryBounded attempts, all on record.
ForkNew run from any checkpoint.
ApproveAn approval node waits for you.
CancelEnd a run, keep its history.
ScheduleCron schedules on your machine.

Seven step kinds

Only agent nodes call a model. The rest are plain and predictable.

  • agent
  • shell
  • route
  • verify
  • approval
  • join
  • transform

State stays in your repo

Loopy runs on Bun and calls the agent CLIs you already have, with your login. No hosted compute.

Quick start

Install with Bun. Import a session you already ran. Run what comes out.

# install and set up
bun add -g loopy
loopy init
# session to graph
loopy import session.jsonl --provider codex
loopy extract --import <import-id>
loopy approve <proposal-id>
# run it
loopy run <workflow-id>
loopy ui
