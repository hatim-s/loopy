Do the work once.
Then run it again.

Loopy is a local graph harness for coding agents. You finish a task with Codex or Claude Code. Loopy reads the recorded session, draws out the steps as an execution graph, and runs that graph on your own machine. It stops where a person should decide.

Run 1. Starting.

記録record

A session is already a plan. It just isn't written down.

When an agent fixes something for you, the session trace holds every command, every edit, every check and the moment you said yes. Loopy imports that trace and keeps it.

Then the extractor reads it. It is deterministic and makes no model calls. It proposes a graph, and each node points back to the trace events it came from. You review the proposal and approve it.

  1. 記録record

    Record

    Work with your agent the way you already do. Import the session with loopy import.

  2. 抽出extract

    Extract

    Turn the trace into a proposed graph with loopy extract. Approve it when it reads right.

  3. 実行run

    Run

    Run the graph with loopy run. The agent still does the open-ended work inside its nodes.

Not every trace line becomes a node. bun install stays in the trace. Each node cites the lines behind it, so you can check why it exists.

制御control

A run can wait. It can also be stopped, retried or forked.

Every attempt and checkpoint is written to a SQLite file in your project as it happens. So a run is something you can put down and pick up again.

Pause and resumeThe run stops between nodes and continues from the last checkpoint.
RetryA node runs again within its limit. Each attempt stays on record.
ForkA new run starts from any checkpoint of an old one.
CancelThe run ends and its history stays.
ApprovalThe graph waits for a person before it pushes.
ScheduleA cron schedule starts the graph on your machine.

Seven kinds of step make up a graph. Only the agent step calls a model.

手元at hand

Nothing is hosted. The graph runs where your code is.

Loopy runs on Bun. It starts the agent CLIs you already installed, with your login and your settings. Source, credentials and traces stay on your disk.

State lives in .loopy/loopy.db. To look at a graph, open the local Dashboard with loopy ui and edit nodes and edges in the browser.

始めbegin

Begin with a session you already ran.
