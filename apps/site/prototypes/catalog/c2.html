Issue 1. Graphs from agent sessions.

You did it once. Keep the graph.You did it once. Keep the graph.

Loopy reads a finished Codex or Claude Code session and turns it into a graph of steps. Then it runs that graph on your laptop, and you can pause it, retry a step, fork it, or make it wait for your OK.

Runs on your machinestate in .loopy/loopy.db

Three moves, in this order.

1

Record

Do the task with your agent like you always do. Loopy imports the session trace, every command and edit in order.

loopy import
2

Extract

The extractor reads the trace and proposes a graph. It makes no model calls. Each node cites the trace lines it came from.

loopy extract
3

Run

Loopy runs the graph through the agent CLIs you already have installed, with checks and approvals between the steps.

loopy run

No cloud in this zine.

Loopy runs on Bun and calls the agent CLIs already on your machine. There is a local Studio too. Run loopy ui and edit nodes and edges in the browser.

.loopy/loopy.db
  • runs and checkpoints
  • approvals and schedules
  • imported traces
  • one SQLite file per project

Cut out and keep.

# install
$ bun add -g loopy
$ loopy init

# bring in a session you already ran
$ loopy import session.jsonl --provider claude-code
$ loopy extract --import <import-id>
$ loopy approve <proposal-id>

# run it, then look at it
$ loopy run <workflow-id>
$ loopy ui
