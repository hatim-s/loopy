Loopy is a local graph harness for Codex and Claude Code. It reads a recorded session, extracts an execution graph, and runs that graph on your machine. You can pause it, retry a step, fork from a checkpoint, and approve before anything ships.

1 of 3

Record

Do the task once with your agent. Loopy imports the session trace, every command, edit and check in the order they happened.

Run loopy import session.jsonl --provider codex for a session you already have.

2 of 3

Extract

The extractor turns the trace into a proposed graph. It is deterministic and makes no model calls. Each node on the ring points back to the trace events that produced it.

Run

Approve the proposal and run it with loopy run. The graph goes through the same agent CLIs on your machine. Loopy decides the order, runs the checks and stops at approvals.

The tests fail once in this demo, so you can see the route send the run back to the agent step.

Runtime controls

These buttons drive the ring. Runs are durable, so every attempt and checkpoint is saved to SQLite as it happens.

Quick start

Loopy runs on Bun. State lives in .loopy/loopy.db. Open the local Dashboard with loopy ui.

# install
$ bun add -g loopy
$ loopy init
# session to graph
$ loopy import session.jsonl --provider codex
$ loopy extract --import <import-id>
$ loopy approve <proposal-id>
# run and look
$ loopy run <workflow-id>
$ loopy ui
