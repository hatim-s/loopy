Do it once. Run it as a graph.

loopy is a local graph harness for coding agents. Finish a task in Codex or Claude Code, import the session trace, and Loopy extracts an execution graph you can run again on your own machine. Pause it, retry a node, fork from a checkpoint, or make it wait for your approval.

~/work/apibun

How it works

Three commands. The agent does the open-ended work inside nodes. The graph around it is plain data you can read.

0:record

Record

Do the task once with your agent. Loopy imports the session trace.

$ loopy import s.jsonl \
    --provider codex
214 events
import imp_7f3a
1:extract

Extract

A deterministic extractor proposes a graph. No model calls. Every node cites its trace events.

$ loopy extract \
    --import imp_7f3a
9 nodes, 10 edges
proposal prp_19c2
2:run

Run

Run the approved graph locally through the same agent CLIs, with checks and approvals between steps.

$ loopy run cve-patch
run r_41 started
state .loopy/loopy.db
[loopy] 0:record 1:extract* 2:runlocal

Runtime controls

A run is durable. Every node attempt and checkpoint lands in SQLite, so you can stop it and pick it up later.

loopy pause <run-id>Stop between nodes. Nothing in flight gets killed.
loopy resume <run-id>Continue from the last checkpoint.
loopy retry <run-id> --node <id>Run one node again. Attempts are bounded and each one is kept.
loopy forkStart a new run from any checkpoint of an old one.
loopy cancel <run-id>End the run and keep its history.
loopy approveApproval nodes wait here for a person.
loopy schedule create --cron '0 9 * * *'Run the graph on a cron schedule, on your machine.

Local by default

Loopy runs on Bun. It calls the agent CLIs you already installed, with your login. Source, credentials and traces stay on your disk.

$ tree .loopy
.loopy
└── loopy.db   # runs, checkpoints,
               # approvals, schedules
$ loopy ui
studio: serving on 127.0.0.1
read and edit nodes, edges
and policies in the browser

Quick start

# needs bun
bun add -g loopy
loopy init
loopy import session.jsonl --provider codex
loopy extract --import <import-id>
loopy approve <proposal-id>
loopy run <workflow-id>
loopy ui
