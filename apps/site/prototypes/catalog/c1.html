A loop you can stop.Seven step kinds. One run moving through them.

Loopy is a local graph harness for Codex and Claude Code. Finish a task with your agent once. Loopy reads the session trace, extracts an execution graph, and runs that graph on your machine with pause, retry, fork and approvals.

Quick start How it works

Record. Extract. Run.

The agent still does the work inside each node. The graph decides what happens next, and you can read every edge.

1

Record

Do the task once in Codex or Claude Code. Loopy imports the recorded session as a trace, one event per line.

loopy import
2

Extract

A deterministic extractor proposes a graph. No model calls. Every node points back to the trace events behind it. You review and approve.

loopy extract
3

Run

The graph runs through the same agent CLIs on your machine. Loopy owns the order, the checks and the approvals.

loopy run
agentOpen-ended work in Codex or Claude Code
shellA command with an exit code
routePick the next edge from output
verifyA check that passes or fails
approvalWait for a person
joinWait for every branch
transformReshape data between steps

You hold the controls.

This graph patches a critical dependency CVE. Start it, pause it between nodes, fork from a checkpoint. The tests fail once on purpose so you can watch a retry. The run stops at approval until you press approve.

Retry

Bounded attempts per node, each one on record.

Fork

Branch a new run from any checkpoint.

Approvals

An approval node waits for a person.

Schedules

Cron schedules run the graph on your machine.

Nothing leaves your laptop.

Loopy runs on Bun. It starts the agent CLIs you already installed, with your login and your settings.

.loopy/loopy.db

Runs, checkpoints, approvals and schedules live in one SQLite file inside your project.

Traces export as portable JSONL, one event per line.

Open the local Studio with loopy ui to read and edit nodes, edges and policies.

Quick start

Install with Bun, import a session you already ran, and run the graph it leaves behind.

  1. bun add -g loopyInstall the CLI
  2. loopy initCreate .loopy/loopy.db in this project
  3. loopy import session.jsonl --provider codexBring in a finished session
  4. loopy extract --import <import-id>Propose a graph, then approve it
  5. loopy run <workflow-id>Run it locally
  6. loopy uiOpen Studio
