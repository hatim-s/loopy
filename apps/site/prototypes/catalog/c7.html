Loopy records a coding agent session in Codex or Claude Code and extracts the execution graph inside it. Then it runs that graph on your own machine, where you can pause, retry, fork from a checkpoint, and approve each step that matters.

How a session becomes a graph

The agent still does the open-ended work. Loopy writes down the structure around it, so the next run follows the same steps with checks and approvals in between.

1Record

Do the task once with Codex or Claude Code, the way you already work. Loopy imports the recorded session as a trace, one event per line, and keeps it with your project.

loopy import

2Extract

A deterministic extractor reads the trace and proposes a graph. It makes no model calls. Every node points back to the trace events that produced it. You review the proposal and approve it.

loopy extract

3Run

The approved graph runs on your machine through the same agent CLIs. Loopy decides the order, runs the checks, and stops at approval steps until a person answers.

loopy run
Only the agent step calls a model. Shell, route, verify, approval, join and transform steps do exactly what they say.
The seven step kinds in a Loopy graph

Specification

What the runtime gives you, listed the way a watchmaker lists a movement. Every run is durable, so attempts and checkpoints are written down as they happen.

Movement
Bun. The CLI is loopy.
Complications
Pause, resume, cancel, retry with bounded attempts, fork from a checkpoint, human approvals, cron schedules.
Agents
Codex and Claude Code, through the CLIs you already installed, with your login.
Step kinds
Agent, shell, route, verify, approval, join, transform.
Memory
One SQLite file per project at .loopy/loopy.db.
Case
Your machine. No hosted compute. Source, credentials and traces stay local.
Dial
A local Dashboard for reading and editing graphs. Open it with loopy ui.

Quick start

Install with Bun, bring in a session you already finished, and run the graph it leaves behind.

bun add -g loopy
loopy init
loopy import session.jsonl --provider codex
loopy extract --import <import-id>
loopy approve <proposal-id>
loopy run <workflow-id>
loopy ui          # open Dashboard
