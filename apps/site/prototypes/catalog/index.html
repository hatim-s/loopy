Loopy landing catalog

Seven directions for the landing page. Each one is a single HTML file with its own palette, type and layout, and one interactive piece tied to the product.

Older catalog in variants
c1

Poster

Swiss poster in condensed Archivo, black and one red on off-white. A ring of step kinds turns behind the headline.
c2

Zine

Risograph zine with pink and blue overprint. Trace lines on a receipt fly off and land as graph nodes. The run plays as a board game.
c3

Phosphor

Amber CRT terminal with scanlines. A fake shell you can type loopy commands into, with a live run and key controls.
c4

Isometric

Saturated cobalt bento in Unbounded. The graph is built from CSS 3D blocks you can drag to turn, and nodes rise as the run reaches them.
c5

Ensō

Japanese minimal long-form in Shippori Mincho. A brushed ensō is the loop, and the run waits in its gap until you press the seal.
c6

Sundown

Vaporwave split screen in chrome Michroma. A sticky sunset scene follows your scroll from trace, to nodes, to a run you can control.
c7

Chronograph

Dark luxury magazine in Bodoni Moda and brass. The graph sits on a watch dial, and the crown and pushers start, approve and fork the run.
