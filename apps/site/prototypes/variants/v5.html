Loopy proposes a graph. The extractor is deterministic. Every node links to the trace events that justify it. You review it, edit it, approve it.

Runon your machine

It runs through the same CLIs. Branches, retries and checks happen in order. The push waits for a person.

The runtime handles the fiddly bits

Agents are good at the edit. Loopy decides what happens around it, and keeps a record.

  • Branching

    Conditions send the run down one edge or the other based on real output.

  • Parallel joins

    Fan out to several nodes and wait for all of them before moving on.

  • Retries

    A failed node retries within the limit you set, then stops with the error on record.

  • Approvals

    The run parks at an approval node until someone says yes. Nothing gets pushed before that.

  • Pause, resume, cancel

    Stop between nodes, pick it up tomorrow, or end the run cleanly.

  • Replay

    Run a finished graph again from its recorded inputs and compare.

  • Checkpoint forks

    Branch a new run from any checkpoint instead of starting over.

  • Schedules

    Put a loopy on cron. 0 9 * * * runs it at nine every morning.

Run state lives in a local SQLite file. Traces export as JSONL.

It all runs on your laptop

Loopy calls your agent's CLI as a local subprocess, with the login you already have. There is no hosted compute and nothing to sign up for.

  • Source code stays in your checkout.
  • Credentials stay with the CLIs that already hold them.
  • Subprocesses run under your user, on your machine.
  • Traces stay on disk until you export them.
