Hero variants

Five takes on the v7 hero. Same copy, same nav, same reveal timing. What changes is the background behind the text and how bold the headline is set. Each page is one viewport tall; use the switcher in the bottom right corner to flip between them.

  1. h1Flickering dot grid

    A 28px grid of dots that each pick a new brightness on their own slow schedule. The pointer lifts the dots near it. The grid fades at the viewport edges and under the text.

    Type: weight 600, up to 76px, third line in the brand gradient.

  2. h2Drifting constellation

    Sparse points drifting slowly, with thin lines joining any two within reach, so small graphs form and dissolve. The pointer pushes points away.

    Type: weight 500 kept from v7 but set larger with line-height 1.0, gradient on the word control only.

  3. h3Aurora mesh with grain

    Three soft blobs in accent and aqua, low saturation, each on a 23 to 33 second loop, with a grain tile on top. No dots.

    Type: weight 600, with a thin gradient rule drawn under the second line once it lands.

  4. h4Glyph field with a sweeping band

    A grid of tiny mono glyphs that swap now and then. A diagonal band sweeps across every 12 seconds and brightens what it passes, tinted from accent to aqua left to right.

    Type: weight 600, line-height 1.0, lines rise out of a clipped box, no gradient text.

  5. h5Line topology with travelling beads

    Thin horizontal lines that bend away from the pointer like a field, with a few bright beads running along them, the same token that marks a running node in the studio.

    Type: weight 600, mask reveal, gradient on the word control.

All five run on one canvas with requestAnimationFrame, cap the pixel ratio at 2, pause when the tab is hidden, and draw a single still frame when the visitor prefers reduced motion.
