Install

Do the work once.Extract the graph.Run it with control.

Finish a task once in your agent CLI, and Loopy turns that session into a graph you can read, edit and run again on your own machine.

$ bun add -g loopy

Then open loopy studio and point it at a session.

A session goes in. A graph comes out.

Loopy keeps the shape of what you did and drops the rest.

  1. 01

    Capture loopy import

    Do the task once in Codex, Claude Code, OpenCode or Pi. Loopy records the session as a trace.

  2. 02

    Extract loopy extract

    A deterministic extractor proposes a graph, no model calls. Every node points back to its trace events.

  3. 03

    Run loopy run

    The graph runs on your machine through the same CLIs. Loopy owns the order, the checks and the approvals.

The agent does the work. The graph decides what happens next.

Inside a node the agent loops as long as it needs. Between nodes, Loopy runs plain rules you can read.

Branching

Conditions route the run down one edge or another.

Parallel joins

Fan out to several nodes and wait for all of them.

Retries

Failed nodes retry within your limits, then stop with the error on record.

Approvals

The run waits until a person says yes.

Pause, resume, cancel

Stop a run between nodes and pick it up later.

Replay

Run a finished graph again from its recorded inputs.

Checkpoint forks

Branch a new run from any checkpoint.

Schedules

Put a loopy on cron. 0 9 * * * runs it every morning.

Keep the agent you already use. Your laptop does the work.

Loopy calls the CLI you have installed, with your login and your settings. No hosted compute.

  • Open source under Apache-2.0.
