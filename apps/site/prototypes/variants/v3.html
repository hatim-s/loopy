Do the work once. Extract the graph. Run it with control.

Loopy reads the session you already finished with a coding agent and draws the graph hiding inside it. Then it runs that graph on your machine, with checks and approvals where you want them.

$ bun add -g loopy

Sheet 2runtime

Agents loop inside nodes. The graph owns everything between them.

A node's state only changes through the transitions below. This one is running for real, on a loop.

    BranchingConditions route on real output
    Parallel joinsFan out, wait for all
    RetriesBounded, each attempt kept
    ApprovalsThe run waits for a person
    Pause and resumeBetween nodes, any time
    CancelEnds cleanly, history kept
    ReplaySame inputs, fresh run
    Checkpoint forksBranch from any checkpoint
