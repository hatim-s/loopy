Install

Do the work once.Extract the graph.Run it with control.

Loopy is a local-first graph harness for coding agents. Finish a task once in your agent CLI. Loopy turns that session into a graph you can read, edit and run again on your own machine.

$ bun add -g loopy

Then open loopy ui and point it at a session.

A session goes in. A graph comes out.

You already know how to get the task done. Loopy keeps the shape of what you did and drops the rest.

  1. Capture

    Do the task once in Codex, Claude Code, OpenCode or Pi, the way you would anyway. Loopy records the session as a trace, or imports one you ran last week.

    $ loopy import session.json --provider codex

  2. Extract

    A deterministic extractor reads the trace and proposes a graph. It makes no model calls, so the same trace gives the same graph. Every node links back to the trace events that justify it. You edit what you disagree with, then approve.

    $ loopy extract --import <id>
    $ loopy approve <id>

  3. Run

    The graph runs on your machine through the same CLIs you used. The agent does the work inside each node. Loopy decides what happens between them.

    $ loopy run

Between nodes, the rules are yours to read.

Inside a node the agent can loop as long as it needs. Out here, the runtime follows the graph and writes down every step.

Branching
A condition node reads real output and sends the run down one edge.
Parallel joins
Fan out to several nodes and wait for all of them before moving on.
Retries
A failed node goes round again within the limit you set, then stops with the error on record.
Approvals
The run holds at an approval node until a person says yes.
Pause, resume, cancel
Stop between nodes, come back tomorrow, or end the run cleanly.
Replay
Run a finished graph again from its recorded inputs.
Checkpoint forks
Start a new run from any checkpoint instead of from the top.
Schedules
Put a loopy on cron and it runs while you sleep.

Keep the agent you already use.

Loopy calls the CLI you have installed, with your login and your settings. One graph can mix them.

No hosted compute. Your laptop does the work.

Loopy is a process on your machine that starts other processes on your machine.

  • Source, credentials, subprocesses and traces stay local.
  • Run state lives in SQLite on disk.
  • Traces export as JSONL, so any tool can read them.
  • Schedules run on cron.loopy schedule create --cron '0 9 * * *'
  • Open source under Apache-2.0.

Patch critical dependency CVEs.

We fixed a lodash advisory in Codex once. This is the graph Loopy extracted from that session. Each node lists the trace events it came from.

  1. e1bun audit --json
  2. e2npm view lodash versions
  3. e34.17.21 fixes CVE-2021-23337
  4. e4edit package.json lodash ^4.17.21
  5. e5bun install
  6. e6bun run check 412 passed
  7. e7"diff looks right, push it"
  8. e8git push
  9. e9gh pr create --fill

Keep open pull requests rebased

Our other daily loopy. At nine it lists open PRs, has an agent rebase each onto main, runs a focused check and pushes with --force-with-lease. Conflicts get skipped.

loopy schedule create --cron '0 9 * * *'
