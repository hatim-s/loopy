Turn one agent session into a graph you can run

Loopy imports a Codex or Claude Code session, extracts the steps as an execution graph, and runs that graph on your machine. You get pause, resume, approvals and cron. State stays in a local SQLite file.

Runs on a schedule

loopy schedule create puts a graph on cron. It runs on your machine with your Git credentials.

No hosted compute

Runs, checkpoints and approvals live in .loopy/loopy.db. Source, credentials and traces stay on your machine.

Read and edit every graph in Dashboard

loopy ui opens a local editor with seven step kinds, version history, and a run console that shows each attempt as it happens.

Three steps from a finished task to a graph that runs

Each step writes to disk, so you can inspect it before the next one starts.

1

Record

Do the task once in Codex or Claude Code, the way you normally would. Loopy imports the session as a trace.

$loopy import
2

Extract

Loopy proposes a graph from the trace. Open it in Dashboard, change what you disagree with, then approve it.

$loopy extract
3

Run

The graph runs through the same CLI you recorded with. Loopy owns the order, the checks and the approvals.

$loopy run

Try it on a session you already have

From install to a running graph in Dashboard, with a review step in the middle.

  • Needs Bun and a signed-in Codex or Claude Code CLI
  • loopy init creates .loopy/ in your repo
  • Loopy calls your installed CLI with your login and settings
Terminal
# install the CLI
$ bun add -g loopy

# set up .loopy/ in your repo
$ loopy init

# bring in a finished session, extract a graph
$ loopy import trace.jsonl --provider codex
$ loopy extract --import <import-id>

# review the proposal, run it, open Dashboard
$ loopy approve <proposal-id>
$ loopy run <workflow-id>
$ loopy ui
