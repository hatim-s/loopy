Your agent's best session, now a run you can replay

Loopy extracts an execution graph from a Codex or Claude Code session and runs it on your machine. Every step, retry and approval lands in a local SQLite file you can inspect, pause, resume or fork.

      Quick start
      
      
      Needs Bun and a signed-in Codex or Claude Code CLI. Loopy calls it with your login and settings.
      
      
        
        
      • loopy initCreates .loopy/ in your repo
        • 
        
      • loopy importBrings in a session trace
        • 
        
      • loopy extractProposes a graph from the trace
        • 
        
      • loopy runRuns the approved graph
        • 
        
      • loopy uiOpens Studio in your browser
        • 
      
      
    
      
    
      
      
      Terminal
      

      # install and set up
$ bun add -g loopy
$ loopy init

# import a session, extract and approve a graph
$ loopy import trace.jsonl --provider codex
$ loopy extract --import <import-id>
$ loopy approve <proposal-id>

# run it, then open Studio
$ loopy run <workflow-id>
$ loopy ui
