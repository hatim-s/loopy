How a session becomes a graph

Record loopy import

Do the task once in Codex or Claude Code. Loopy imports the session as a trace.

Extract loopy extract

The extractor proposes nodes and edges. No model calls. Each node links to its evidence.

Run loopy run

The graph runs through the same CLI. Loopy owns the order, checks and approvals.

What the graph gives you that a chat session can't

A session happens once. A graph keeps the steps, the gates and the history, so you can run it again tomorrow and see exactly what happened.

Start with a session you already have

Pick the agent you recorded with. The rest of the flow is the same.

Terminal
# install and set up .loopy/ in your repo
$ bun add -g loopy
$ loopy init

# import the session and extract a graph
$ loopy import trace.jsonl --provider codex
$ loopy extract --import <import-id>
$ loopy approve <proposal-id>

# run it and watch it in Dashboard
$ loopy run <workflow-id>
$ loopy ui

Needs Bun and a signed-in agent CLI. Loopy calls it with your login and settings.
